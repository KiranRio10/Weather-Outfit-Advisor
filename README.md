# 🌤️ SkyWear - Weather & Smart Outfit Advisor

SkyWear is a modern weather dashboard that combines real-time weather forecasting with intelligent outfit recommendations.

Built with a premium glassmorphism UI, dynamic weather themes, and a smart recommendation engine, SkyWear helps users decide what to wear based on live weather conditions.

---

## 🚀 Features

### 🌍 Real-Time Weather Data
- Current weather conditions
- Temperature
- Humidity
- Wind speed
- Rain probability
- Weather descriptions

### 🔍 Smart City Search
- Global city search
- Autocomplete suggestions
- Open-Meteo Geocoding API integration

### 👕 Smart Outfit Recommendation Engine
Recommendations based on:

- Temperature
- Wind Speed
- Rain Probability
- UV Index
- Snow Conditions
- Weather Codes

Suggested:

- Outerwear
- Tops
- Bottoms
- Footwear
- Accessories

### 📊 Forecast Visualization

#### Hourly Forecast
- Next 12 Hours
- Dynamic SVG Temperature Chart

#### Weekly Forecast
- 7-Day Forecast
- Daily High/Low Temperatures

### 📈 Weather Analytics

- UV Index
- Pressure
- Visibility
- Wind Direction

### 🎨 Dynamic Weather Themes

Automatically changes UI themes:

- Sunny
- Cloudy
- Rainy
- Snowy

### 🌡️ Unit Conversion

Switch between:

- Celsius (°C)
- Fahrenheit (°F)
